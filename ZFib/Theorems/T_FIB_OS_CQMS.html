        theorem ZFib.Theorems.FibOSCQMS.lipNorm_zero_iff_scalar_firstBand {M : ℕ} (hM : 2 ≤ M) (c0 c1 cm1 : ℂ) :
        (∀ (j : ℕ), (External.OperatorAlgebra.AnalyticClosure.Fibonacci.fibNumberOpTrunc M) ((c0 • FibOSTruncation.fibCutoffProj M + c1 • FibOSTruncation.fibCompS M + cm1 • FibOSTruncation.fibCompSstar M) (External.OperatorAlgebra.AnalyticClosure.Fibonacci.fibOSInfBasis j)) - (c0 • FibOSTruncation.fibCutoffProj M + c1 • FibOSTruncation.fibCompS M + cm1 • FibOSTruncation.fibCompSstar M) ((External.OperatorAlgebra.AnalyticClosure.Fibonacci.fibNumberOpTrunc M) (External.OperatorAlgebra.AnalyticClosure.Fibonacci.fibOSInfBasis j)) = 0) ↔ c1 = 0 ∧ cm1 = 0

        R1b — kernel = scalars on the first-band shift-symbol space.

        For a first-band truncated-Toeplitz symbol a = c0 • Q_M + c1 • S_M + cm1 • S*_M, the Lip-norm vanishes ([N_M, a] = 0 on every basis vector) iff c1 = 0 ∧ cm1 = 0, i.e. iff a = c0 • Q_M ∈ ℂ·Q_M.

        Mechanism: [N_M, Q_M] = 0, [N_M, S_M] = S_M, [N_M, S*_M] = −S*_M, so [N_M, a] = c1 • S_M − cm1 • S*_M (the band-1 and band-(−1) pieces, eigen-bands of the derivation with eigenvalues +1 and −1). These two operators have disjoint band support, hence are linearly independent; the commutator is 0 iff both coefficients vanish.

        We prove the substantive direction at the SEPARATING basis vectors: evaluating [N_M, a] at e_0 isolates c1 (only S_M e_0 = e_1 survives), and at e_M isolates cm1 (only S*_M e_M = e_{M-1} survives, since S_M e_M = 0 is the leak).
