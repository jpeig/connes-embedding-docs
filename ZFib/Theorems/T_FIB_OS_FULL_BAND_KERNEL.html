        c = 0 ∧ d = 0

        Full-band kernel-scalar — single band pair.

        If [N_M, c₀•Q_M + c•S_M^p + d•S_M^{*p}] = 0 on every basis vector (1 ≤ p ≤ M, M ≥ 1), then c = 0 ∧ d = 0. The band-0 coefficient c₀ is free (it is the kernel direction ℂ·Q_M).

        Mechanism (the full-band generalisation of the first-band e_0/e_M separation): evaluate the reduction fibComm_bandPair_reduction at the two separating modes —

        • at e_0: S_M^p e_0 = e_p ≠ 0, S_M^{*p} e_0 = 0 ⟹ (c·p)•e_p = 0 ⟹ c·p = 0 ⟹ c = 0 (since p ≥ 1);
        • at e_M: S_M^p e_M = 0, S_M^{*p} e_M = e_{M−p} ≠ 0 ⟹ −(d·p)•e_{M−p} = 0 ⟹ d·p = 0 ⟹ d = 0.

        The disjoint support at the separating modes is what e_0/e_M deliver: each mode kills one of the two bands, isolating the other coefficient.
